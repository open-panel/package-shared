# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project uses
[Semantic Versioning](https://semver.org/).

## [0.1.0]

### Added

- Domain types and zod schemas for profiles, pages, buttons and actions.
- Device info, capabilities and event schemas.
- Theme manifest/palette schemas, derivation and color math (OKLab-based
  contrast, mixing, alpha).
- Locale schemas and matching/resolution helpers.
- Log entry and IPC event map types.
